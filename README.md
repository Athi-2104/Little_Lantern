# 🏮 Little Lantern

Little Lantern is a web application developed using PHP to provide a simple and user-friendly platform.

## Features

- User Authentication
- Responsive Interface
- Database Connectivity
- CRUD Operations

## Technologies

- PHP
- HTML
- CSS
- MySQL

## Installation

1. Clone the repository
2. Import the database
3. Configure PHP
4. Run using XAMPP

## Future Scope

- Admin Panel
- Reports
